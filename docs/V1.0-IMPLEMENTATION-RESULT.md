## Explicit blockers to commercial production

TrustRelay v1.0 will not call itself commercially live until:

- separate production Supabase environment is approved/provisioned
- Stripe live provider/secrets/price IDs are configured
- legal entity is confirmed
- counsel approves and effective binding legal package is published
- custom domain is attached
- custom SMTP is configured
- database SSL/network controls are confirmed
- backup/PITR and restore exercise are confirmed
- monitored security contact exists
- evidence malware scanning is integrated
- production reviewer governance is approved
- retention automation is implemented
- privacy-request operations are staffed
- Auth abuse/CAPTCHA controls are confirmed
- incident response ownership is assigned

The production activation engine enforces these controls rather than relying on a checklist alone.

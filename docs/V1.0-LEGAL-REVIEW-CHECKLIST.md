# TrustRelay v1.0 Legal / Compliance Review Checklist

This checklist is not legal advice. It identifies items that require qualified legal/business review before TrustRelay treats its draft package as binding.

## Corporate/commercial

- contracting legal entity name and address
- governing law/venue
- customer order/checkout contracting flow
- pricing, taxes and refund/cancellation terms
- warranty disclaimers
- liability cap/exclusions
- indemnities
- suspension/termination
- SLA/support commitments if offered

## Privacy

- controller/processor roles by workflow
- U.S. state privacy obligations
- data subject/request process and deadlines
- identity-document retention/deletion
- enterprise customer instructions
- international transfers/SCCs if applicable
- subprocessor notice process
- incident/breach notice obligations

## Identity / delegated authority

- permitted product claims
- distinction from power of attorney/notarization/government credentials
- institutional reliance language
- sector-specific obligations for target customers
- manual identity reviewer governance
- external KYC provider terms if added

## Binding publication

Only after counsel approval should service-role operations mark the canonical legal documents:
- counsel_reviewed=true
- binding=true
- effective_at set
- content SHA-256 fixed

The v1.0 onboarding engine then requires the current effective versions to be accepted.

## Security properties verified

- Destination must be HTTPS.
- Userinfo in destination URLs is rejected.
- Destination A/AAAA records are resolved immediately before delivery.
- Private/reserved IPv4 and IPv6 targets are rejected.
- All resolved answers must be acceptable public addresses.
- The outbound TCP connection is opened directly to the validated IP.
- TLS certificate validation and SNI use the original destination hostname.
- HTTP redirects are not followed.
- Internal dispatcher-to-egress authentication uses a high-entropy Vault-backed secret.
- Customer delivery HMAC remains `v1=HMAC_SHA256(<timestamp>.<raw JSON body>)`.
- Delivery responses are bounded before persistence.

## Organization roles

Implemented roles:

- owner
- admin
- compliance
- verifier
- developer
- auditor

### Owner

Full organization/member/role/API/webhook/decision/evidence/audit/export authority, including ownership transfer.

### Admin

Broad operational access, but cannot transfer ownership, mutate the owner, or perform owner-only peer-administration operations.

### Compliance

Can read decisions/evidence, review evidence, read the organization audit trail, and create compliance exports. Cannot manage members, API keys, or webhooks.

### Verifier

Can evaluate authority and work with evidence. Cannot receive API-key metadata, webhook configuration/history, team administration data, organization audit history, or compliance exports.

### Developer

Can manage Partner API keys and webhooks and read decision/audit data. Cannot receive evidence-request or team-management data and cannot create compliance exports.

### Auditor

Can read decisions/evidence/audit history and create compliance exports, but cannot mutate operational configuration.

## Export integrity and hash chaining

The exact generated artifact receives SHA-256.

The source dataset SHA-256 is stored in the manifest.

Each ready export also participates in a per-organization export hash chain:

`SHA256(previous_export_hash | export_id | organization_id | content_sha256 | manifest_json | created_at)`

Stored evidence includes:

- contentSha256
- previousExportHash
- exportHash
- manifest
- rowCount
- sizeBytes
- completedAt
- expiresAt

A completed export generates:

- organization audit event
- canonical in-app notification
- `compliance.export.ready` webhook event

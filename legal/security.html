Security Statement

PRODUCTION-CANDIDATE STATEMENT. This page describes implemented controls but does not claim SOC 2, ISO 27001, PCI DSS, HIPAA or other certification.

Authentication

Passwordless email magic-link/OTP for users. Sensitive internal reviewer privileges are separately provisioned.

Authorization

Organization RBAC, scoped API keys, grant-specific policy evaluation and server-side privileged functions.

Private data

Identity evidence and compliance exports use private object storage and short-lived signed URLs.

Integrity

ES256 credentials, SHA-256 evidence/export hashes, and hash-chained organization audit events.

Webhooks

Vault-backed secrets, canonical JSON, HMAC-SHA256 signatures, retries, attempt logs and dead-letter state.

Database

Public-schema application tables use RLS with restrictive client-deny policies; privileged access is server-side.

Known launch controls still requiring operator confirmation

  • Separate production Supabase project / environment isolation.
  • Custom production domain.
  • Custom SMTP and production email deliverability.
  • Supabase SSL enforcement/network restrictions confirmation.
  • Paid-plan backup/PITR and recovery procedure.
  • Monitored security contact.

Current non-claims

TrustRelay does not currently claim biometric identity matching, liveness detection, AML/sanctions screening, regulatory KYC certification, or independent security-framework certification.
